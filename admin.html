Paste data into Google Sheets

📋 Click "Copy mapped data" below, then follow the 3 steps to publish on Google Sheets.
1️⃣
Open Google Sheets Go to sheets.google.com → create a New spreadsheet
2️⃣
Paste the data Click cell A1 → press Ctrl+V (or Cmd+V on Mac) to paste all rows
3️⃣
Publish as CSV Go to File → Share → Publish to web
Select: Sheet1 · Format: Comma-separated values (.csv)
Click Publish → copy the URL shown
4️⃣
Paste the URL below in Step 4 The URL looks like:
https://docs.google.com/spreadsheets/d/…/pub?gid=0&single=true&output=csv
💡 For daily updates: just paste new data into the same sheet and re-publish (or it auto-refreshes if already published). The JCA link never changes.
